# Saudi Crude Oil Exports Time Series Analysis

## Overview


This project focuses on analyzing and forecasting **Saudi Arabia's Crude Oil Exports** (2002–2025) using advanced Time Series techniques. The analysis compares traditional statistical models with modern Machine Learning and Deep Learning approaches to identify the most accurate forecasting methods..

Data Source:** King Abdullah Petroleum Studies and Research Center (**KAPSARC**).



## Methodologies

- **Exploratory Data Analysis (EDA):** Trend and seasonality decomposition.
- **Stationarity Testing:** Augmented Dickey-Fuller (ADF) test.
- **Statistical Models:** ARMA, ARIMA, and **SARIMA**.
- **Advanced Modeling:** Machine Learning and **Deep Learning** (Simple RNN/LSTM/GRU).
- **Evaluation:** Model comparison using RMSE and MAE.



## Tools & Tech Stack

* **Language:** Python 
* **Data Science:** Pandas, NumPy
* **Visualization:** Matplotlib, Seaborn
* **Time Series:** Statsmodels
* **Machine Learning:** Scikit-learn
* **Deep Learning:** TensorFlow



## Project Workflow

1.  **Data Preprocessing:** Handling missing values and data cleaning.
2.  **Visual Analysis:** Identifying historical trends and seasonal cycles.
3.  **Stability Check:** Testing for stationarity using the ADF test.
4.  **Modeling:** Implementing ARMA, ARIMA, and seasonal models.
5.  **Comparative Study:** Evaluating the performance of AI models vs. statistical models.
6.  **Forecasting:** Generating future predictions for oil export volumes.



## Key Results 

* **Seasonality:** Identified clear seasonal patterns influenced by global demand fluctuations.
* **Model Performance:** Modern AI models showed higher resilience in capturing market volatility compared to traditional methods.
* **Forecasting:** Successfully generated baseline predictions for future export trends until 2025/2026.
